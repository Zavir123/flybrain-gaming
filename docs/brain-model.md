# 模型与接口说明

## 数据和权重

数据：MaleCNS v1.0，`minconf-0.5`，以非空 superclass 选择细胞，不使用 status 过滤。保留所选细胞之间的全部连接，未设连接强度阈值。矩阵为 `W[post, pre]` 的 float32 CSR。原始边权为突触数量，重复边先合并，再按照目标神经元输入绝对权重总和归一化。

递质简化：GABA、glutamate、histamine 统一作为负号，其他或未知递质作为正号。真实效果依赖受体等条件，本映射不是普适生物规律，多巴胺等复杂调质作用也未恢复。

## 视觉

感光细胞根据 `flywireType`（缺失时使用 `type`）选择 R1-6 / R7 / R8，共 6,006 个。使用 rootSide 等注释区分左右眼，每侧按确定性网格映射到缩小后的画面。没有引入实测光轴或复眼几何。红色对比度、亮度和绝对时间差形成输入：

```text
sensory = clip(0.45 × luminance + 1.5 × temporal_difference
               + 0.6 × red_opponency, 0, 1)
```

游戏区域截图含玩家、子弹、敌机及背景，HUD 和监控面板在取图后才绘制，不进入网络。引擎知道的目标坐标、血量等不进入解码器；击杀和实际扣血单独编码为非视觉刺激。

## 动力学

目标每 25 ms 更新一次，膜时间常数 120 ms：

```text
v = exp(-dt / tau) × v + 1.5 × W @ previous_spikes + 0.18 + noise
v[photoreceptors] += 0.8 × sensory
v[PAM] += 0.35 × min(1, reward_remaining / 0.5)
v[PPL1] += 0.35 × min(1, punishment_remaining / 0.5)
spikes = (v >= 1)
v[spikes] = 0
```

`noise` 为每个神经元独立的 Bernoulli 背景驱动，概率 `1.2 × dt`，幅度 0.22，默认种子 64。没有学习、资格迹或权重更新。网络活动不全由画面引起，因此通过有控制的视觉干预验证输入确实影响输出。

## 奖励与惩罚刺激

击杀一架敌机（普通子弹、超级子弹、分身或炸弹）产生一次奖励；敌弹或碰撞导致实际扣血时产生一次惩罚。无敌或护盾阻挡伤害时不触发，敌机逃离或撞毁不计击杀奖励。人工和果蝇驾驶均发送刺激。

真实缓存按 `types` 的 PAM / PPL1 前缀选取两个群体，当前数据分别为 316 / 16 个神经元。将两者作为奖励/惩罚入口是本游戏的工程映射，不代表复原了真实调质、效价编码或学习机制。合成演示网络使用两个独立的 40 节点群体，不声称它们是真实 PAM/PPL1 神经元。

每次事件在对应通道增加 0.5 秒神经时间的剩余刺激，最多累积至 1 秒；每步向目标群体加上最多 0.35 的膜电位电流，并在剩余不足 0.5 秒时线性衰减。奖励与惩罚分别保留，同时发生也不会互相抵消。刺激改变阈上放电，随后通过原有连接传播，动作仍只由下行群体活动解码。固定权重意味着这不是强化学习，不能据此声称已经学会趋利避害。

主线程累计事件次数，脑线程独占执行刺激与模型更新，视觉帧替换不会丢失事件。结束时的致命受击仍消费一次刺激并生成最后快照，之后神经仿真冻结。暂停冻结神经时间；重开清除未消费事件与剩余刺激，保留其余神经状态和累计次数。JSONL 的 `stimulation` 记录触发次数，`tick.stimulation` 记录已消费次数与剩余神经时间，可用于核对。

## 动作解码

对最近 10 个神经时间步（250 ms）的群体放电取均值。这里的运动语义是为游戏人工指定的：

| 群体 | 用途 |
|---|---|
| 左右 DNa02 / DNg13 | 左右活动差决定横向速度 |
| DNg100 | 决定纵向速度与射击开关 |
| DNp01 / DNp10 | 高活动触发炸弹，有十秒神经时间冷却 |

横向速度 `clip(9 × (right-left), -1, 1)`，再进行 0.65/0.35 平滑；纵向速度 `clip(3 × (0.12-forward), -0.6, 0.6)`，再进行 0.8/0.2 平滑。放电率在解码计算中是每神经时间步的平均脉冲数，面板除以 dt 显示 Hz。小于 0.06 的速度进入死区。前进活动超过 0.025 时射击；逃逸活动超过 0.42 时请求一次炸弹。初始化有短暂等待期。

这些阈值保证信号可以转换成可见动作，不表示这些神经元天然对应战机射击或炸弹。效果取决于参数、视野映射和游戏难度，不承诺高分或学会躲避。

## 实时与控制权

只有脑线程修改模型。主线程采集最新画面、读出不可变快照并运行游戏；不等待神经推理。没有待执行帧队列。**人工模式仍持续传入画面、进行神经仿真、更新放电和脑建议，只不执行这些建议。**空格切换只改变动作控制权，不中断感觉或重置脑状态。

感知 epoch 在暂停/重启等边界更新，旧 epoch 的推理结果不会发布；独立的 control_epoch 在人工/果蝇切换时更新，脑状态仍可发布，但切回果蝇后只接受在新控制周期中开始计算的结果，避免积压炸弹或移动动作。暂停、游戏结束和失焦才停止神经仿真。保持感知没有引入模仿学习，权重仍固定。

300 ms 输入/输出超时保护使用单调时钟。炸弹请求在主线程第一次读出时消费，避免在一个神经时间步内被多个游戏帧重复执行。神经线程异常时切为人工，面板显示错误；不悄悄替换模型。

## 显示口径

- 当前放电：最后一个神经步实际超过阈值的神经元数。
- 累计脉冲：所有完成神经步的放电数累加。
- 3D 点云：从具有测量位置的神经元中固定抽样最多 1,800 个，使用 XYZ 三维坐标、可拖动的 yaw/pitch 相机、透视除法和从远到近的深度排序。发亮程度由放电后的指数衰减活动决定，远处点另外衰减亮度以显示深度。它不是完整的神经元形态渲染。滚轮缩放、右键复位，暂停时仍可调整视角。
- RTF：本次连接期间的模拟神经时间 / 实际经过时间。低于 1 表示神经计算慢于目标速率。
- 图中颜色和放电率轴固定，不按当前帧最大值自动拉伸。
- 人工接管时持续更新快照、视觉、脑图和时间线，并分别显示脑建议与实际操作；仅暂停/结束时保留最后快照并显示冻结。
- 合成演示网络含人工构造的视觉到运动连接，只有在演示模式运行，并持续标明来源。
